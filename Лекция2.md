# Введенние C++
## Язык программирования C++
Язык программирования С++ представляет высокоуровневый, компелируемый язык программирования общего назначания со статической типизации. Своими корнями он ухгодит в язык С,который был разработан в 1969-1973гг. в клмпании Bell Labs, программистом Деннис Ритчи.
В начале 80-х датский программист Бьерн Страуструп работал в компании Bell Labs и разработал С++ как расширении к языку С. Фактически в начале язык С++ просто дополнял С с некоторыми возможностями ООП. Изначально язык назывался С с классами.
С++ является компелируемым языком, а это значит, что компелятор транслирует исходный код на С++ в исполняемый файл, который использует набор машиных инструкций. 
Основные компеляторы: 
1)g++
2)clang
3)компелятор от Microsoft VS

## Зачем компелировать файлы
Исходные С++ файл это всего лишь код,но его не возможно запустить как программу и использовать как библиотек,поэтоиу каждый исходный файл требуется скомпелировать в исполняемый.
# Этапы компеляции
1)препроцессинг - это макропроцессор,который преобразовывавет программу для дальнейшего компелирования, на данной стадии происходит работа предпроцейссорными дерективами.Например,предпроцессор добавляет хедеры в код (#include) ,убирает комментарий.<br>
2)Компеляция - образовывает асеблерный код. Это промежуточный этап между высокоуровневым языком и машиным кодом.<br>
3)Асамблирование - перевод асемблированого кода в машиный. Объуктный файл - это созданый асемблером промежуточный файл, хранящий машиный код. Этот кусок машиного кода, который еще не был связан вместо с другими кусками машиного кода, называется объектным кодом.<br>
4)Компановка - компановщик (линкер) связывает все объектные файлы и статические библиотеки в единый исполняемый файл.<br>

# Задание 1
Файлы решения и проекта
.sln (Solution файл)
· Главный файл решения, объединяющий все проекты
· Содержит информацию о конфигурациях сборки
· Текстовый формат, можно редактировать вручную
· Хранит ссылки на проекты и их взаимосвязи

.vcxproj (Project файл)

· Файл проекта C++ (заменил старый .vcproj)
· Содержит все настройки компиляции
· Список исходных файлов, заголовков, ресурсов
· Настройки для разных конфигураций (Debug/Release)
· XML формат

.vcxproj.filters

· Определяет виртуальные папки в Solution Explorer
· Организует файлы по категориям (Source Files, Header Files и т.д.)
· Работает только для удобства навигации

.vcxproj.user

· Локальные пользовательские настройки
· Не следует добавлять в систему контроля версий
· Содержит персональные настройки отладки

📂 Стандартные папки проекта

Source Files (Исходные файлы)

· .cpp - файлы реализации
· .c - файлы на чистом C
· .cc, .cxx - альтернативные расширения

Header Files (Заголовочные файлы)

· .h - заголовочные файлы
· .hpp - C++ заголовочные файлы
· .inl - inline-реализации

Resource Files (Файлы ресурсов)

· .rc - файлы ресурсов (иконки, меню, диалоги)
· .ico - иконки
· .bmp - изображения
· .manifest - файлы манифеста

📄 Типовые файлы C++ проекта

Основные файлы

```cpp
// main.cpp - точка входа в программу
#include "MyClass.h"

int main() {
    // код программы
    return 0;
}
```

stdafx.h / pch.h (Precompiled Header)

· Предварительно скомпилированный заголовок
· Ускоряет компиляцию
· Содержит часто используемые заголовки

stdafx.cpp / pch.cpp

· Компилирует precompiled header
· Обычно содержит только #include "pch.h"

targetver.h

· Определяет целевую версию Windows
· Содержит макросы _WIN32_WINNT и др.

dllmain.cpp (для DLL проектов)

· Точка входа для DLL
· Обрабатывает подключение/отключение DLL

framework.h

· Включает базовые заголовки Windows
· Содержит общие определения

🔧 Конфигурационные файлы

Debug/Release папки

· Debug/ - отладочная сборка
  · .exe - исполняемый файл
  · .pdb - отладочная информация
  · .obj - объектные файлы
· Release/ - релизная сборка
  · Оптимизированный код
  · Без отладочной информации

Промежуточные файлы

· x64/Debug/ - 64-битная отладка
· x86/Release/ - 32-битный релиз
· .obj - объектные файлы
· .pch - precompiled header
· .tlog - логи компиляции
· .log - логи сборки

📝 Пример структуры проекта

```
MyProject/
├── MyProject.sln # Решение
├── MyProject/
│ ├── MyProject.vcxproj # Проект
│ ├── MyProject.vcxproj.filters
│ ├── MyProject.vcxproj.user
│ ├── main.cpp # Главный файл
│ ├── MyClass.h # Заголовок класса
│ ├── MyClass.cpp # Реализация класса
│ ├── pch.h # Precompiled header
│ ├── pch.cpp
│ ├── framework.h
│ ├── Resource.h # Ресурсы
│ ├── MyProject.rc # Файл ресурсов
│ ├── Debug/ # Debug сборка
│ │ └── MyProject.exe
│ └── Release/ # Release сборка
│ └── MyProject.exe
└── .vs/ # Настройки Visual Studio
```

🎯 Назначение каждого файла

Файл Назначение
.sln Объединяет проекты, настройки решения
.vcxproj Основной файл проекта, настройки компиляции
.cpp Исходный код программы
.h Объявления классов и функций
pch.h Ускорение компиляции
.rc Ресурсы приложения
.pdb Отладочная информация
.exe Готовый исполняемый файл
.obj Промежуточные объектные файлы

Каждый файл играет свою роль в процессе разработки, компиляции и выполнения программы.
